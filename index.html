PANDUAN PENGGUNAAN

1. Mengganti Nama Perangkat

Ketuk tulisan DLMS CUSTOM di pojok kiri atas halaman depan untuk mengganti nama sesuai selera Anda (akan tersimpan otomatis).

2. Pengaturan Dasar

Tekan tombol CONNECT BLE di pojok kanan atas untuk menghubungkan HP ke ESP32-S3.

3. Menu Input (L/R)

Gunakan tombol INPUT L atau INPUT R untuk mengatur volume awal (Gain), Mute, dan 1-Band PEQ. Di halaman ini juga terdapat Spectrum Analyzer dan fitur RTA Mic.

4. Menu Output (1-4)

Klik tombol OUT 1 s/d OUT 4 untuk masuk ke pengaturan:

  • HPF & LPF: Memotong nada rendah/tinggi. Gunakan tombol < dan > untuk presisi 1 Hz.
  • PEQ 3-Band: Membentuk karakter suara (bass, mid, treble).
  • Gain, Delay, Limiter: Volume, waktu tunda, dan pengaman speaker.

5. Fitur Gila: GLOBAL LINK

Saat berada di menu Output, klik tombol 🔗 LINK L/R. Jika menyala hijau, seluruh settingan (HPF, LPF, PEQ, Gain, Delay, Limit) di Out 1 akan otomatis dicopy 100% ke Out 2. (Sama halnya jika Anda mengedit di Out 3, maka Out 4 akan ikut).

6. Grafik Drag & Drop (Halaman Depan)

Klik salah satu warna (O1-O4) di pojok grafik, lalu tarik 3 bulatan putih yang muncul ke atas/bawah atau kiri/kanan. Settingan di ESP32 langsung menyesuaikan!

7. Mode RTA vs OSC

Klik tulisan MODE: RTA di atas grafik untuk beralih antara mode grafik batang frekuensi (RTA) dan grafik gelombang suara (OSC).

8. Menyimpan Preset

Tekan tombol SAVE di atas, lalu tekan P1, P2, atau P3. Settingan Anda akan tersimpan di HP dan tidak hilang saat di-refresh.

9. Fitur RTA Mic (BARU!)

Masuk ke menu INPUT L/R, klik tombol 🎤 MULAI RTA MIC. Aplikasi akan menggunakan mikrofon HP Anda untuk menampilkan analisis frekuensi suara di sekitar Anda secara real-time. Sangat berguna untuk tuning speaker!
